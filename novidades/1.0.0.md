# Nexus Field 1.0.0

Primeira versão do Nexus Field para Android.

- O App de Campo em tela cheia, com o ícone do Nexus Field na tela inicial
- A fila, os rascunhos e as fotos ficam guardados no aparelho, para não se perderem se o celular limpar o navegador
- A câmera e a localização são pedidas na primeira abertura, com o motivo explicado
- O aplicativo avisa quando sai uma versão nova e se atualiza com um toque
